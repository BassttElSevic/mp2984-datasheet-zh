# MP2984 前部参数与基本工作原理疑点查证

查证日期：2026-11-11。本文依据用户提供的 MP2984 Rev. 1.0 原稿，交叉检索官方在售页面、官方在线手册、MP2980 同族手册及公开论坛。以下“高可信笔误”是资料交叉与电路分析结论，不是 MPS 发布的正式勘误。没有给原翻译正文作修改。

- **S3：MP2984 官方产品页**：[英文页](https://www.monolithicpower.com/en/products/mp2984.html)、[中文页](https://www.monolithicpower.cn/cn/mp2984.html)。明确采用降压谷值、升压峰值控制，启动输入下限为6 V。

## 逐条结论

| 原稿疑点 | 查证结果 | 分类与把握 |
|---|---|---|
| p5 ILIM 写“两种电平”，随后列四档；ILIMT拼写 | 同页四档描述与p9四级电平阈值相符；S2 p5也明确列四档。这里应理解为四种，ILIMT应是ILIM的拼写失误。注意S2的默认值与部分限流值不同，不能抄其数值来替换MP2984。 | 高可信文字笔误；未找到厂商针对MP2984的正式勘误。 |
| p7 VREF典型值是2.047/0.5，单位却整栏标百分比 | p30的11位无符号编码与1 mV步进确定2.047和0.5为伏；最小/最大项则是相对标称值的误差百分比。它是混合了电压与容差的表格写法，不应把2.047读成2.047%。 | 本手册交叉可确定；主要是表格单位表达欠清楚，而非参考电压功能未知。 |
| p8 IAVGN=5 V与IAVGN=20 V重复列在同一条件格 | S2 p9也保留两个共模电压。更合理的可能解释是分别在5 V和20 V两个共模测试点检测55 µA典型偏置电流。逗号没有说明“分别”，因此仍不能断定测试协议；也没有证据把其中一个引脚名改成IAVGP。 | 应从“矛盾/笔误”降级为测试条件排版歧义；精确测试覆盖仍未确认。 |
| p9注8最低启动值写6而无单位 | S1 p1、p6及S3特性均给6 V启动下限；S2 p10也完整写6 V。 | 缺失单位可由本手册内部确定；应理解为6 V。 |
| p24 SWB导通后电感电流“上升” | 图3的正常正向降压电流定义下，SWB与SWD导通时，电感左端近地、右端近VOUT，故diL/dt≈−VOUT/L，电流应下降。S1 p26又说明降压逐周期限流要等电流降到谷值才开启下一周期；S3确认谷值控制。 | 高可信方向词笔误。电路推导与同手册逻辑一致；未发现MP2984专属厂家更正。 |
| p25 PFM被展开为脉冲宽度调制 | S4明确PFM与PWM是不同术语；PFM对应脉冲频率调制。原句把PFM展开为脉冲宽度调制属于术语不一致。至于MP2984软启动的实际内部调制行为，现有外部资料没有单独证实，不能仅凭通用缩写推导全部启动状态机。 | 术语展开错误为高可信；芯片软启动模式细节仍以厂家确认为准。 |
| p26 FCCM把输入电流写作ILIMIT | S1在p26其他段把ILIMIT用于限流值，且限流阈值不会仅因负载减小而自动减小。此句讨论的是负载减小使实际电流下降，并可能出现反向电感电流，符号ILIMIT很可能误用。仅凭现有资料不能唯一确定作者本想写IIN还是IL。 | 高可信符号误用；不要擅自指定替代符号。 |
| p28 IMON增益18.8 mV/V | S1 p9电气表给18.8 V/V；p11在55 mV检测压差下曲线约1.03 V。55 mV×18.8=1.034 V，吻合；若按18.8 mV/V则小1000倍。式(4)里A×mΩ已经是mV，增益应无量纲。S2 p10也给18.8 V/V。 | 本手册数值、曲线与量纲可交叉确定：应按18.8 V/V理解。 |

## 论坛证据能说明什么

F1 是直接相关的用户测量报告：发帖者称其样板在12 V输入、5 V空载时出现偏离设置频率、输入电流偏大和MOSFET迅速升温；随后提供栅极/漏极波形，并讨论约40 ns死区及FCCM循环电流。回复给出直通、环路稳定性、干扰或PCB布局等排查方向。帖子没有提供最终根因、修复前后对照或正式厂家勘误。现有可见用户名和帖子信息不足以核实回复者的工程师身份；Discourse的staff布尔值仅表示论坛管理权限，也不能用来判断是否MPS员工。因此，该帖能证明用户遇到过相关现象，不能证明芯片设计有问题、默认补偿必然错误或手册上述疑点已获官方确认。

F2的用户代码可说明社区确有串行控制实践，但也存在明显注释质量问题：例如把二进制位串写成带0x前缀的说明、某档电流重复，以及设置CONTROL1时启用了很多不必要位。不能用这段代码反推数据手册勘误。MPSNow_Yu的可见回复仅推荐GUI，没有逐项认证用户代码。
