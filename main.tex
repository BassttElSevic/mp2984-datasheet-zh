\section{概述}
MP2984 是一种高效率的同步四开关升降压控制器，可在宽输入电压（$V_{IN}$）范围内调节不同的输出电压。输出电压（$V_{OUT}$）、输出电压变化率和输出恒流限值可通过 I\textsuperscript{2}C 接口配置。MP2984 适用于 USB Type-C 电源中的 USB Power Delivery（PD）应用。

MP2984 在降压模式采用谷值电流控制，在升压模式采用峰值电流控制，以实现快速负载瞬态响应和平滑的升降压模式过渡。强制连续导通模式（FCCM）及可配置电流限值支持各类应用的灵活设计。

保护功能包括可配置的过流保护（OCP）、过压保护（OVP）和输入欠压锁定（UVLO）迟滞。器件采用 QFN-32（4 mm $\times$ 4 mm）封装。
\section{特性}
\begin{itemize}
\item 工作输入电压范围：5--36 V；启动输入电压范围：6--36 V。
\item 通过 I\textsuperscript{2}C 灵活控制：输出电压范围 0.5--28 V；参考电压范围 0.3--2.047 V，步进 1 mV；可选择输出电压变化率；可配置恒流限值。
\item 通过 IPWM 调节电流限值，步进小于 50 mA；输出电流监测（IMON）。
\item 可配置软启动时间；开关频率扩频以降低 EMI；可选开关频率 200、300、400 或 600 kHz。
\item 集成输出放电；FCCM；可配置输入 UVLO 迟滞；最小输入电压调节。
\item 过流、短路和过压保护；OCP、OVP、OTP 和 PNG 中断指示。
\item QFN-32（4 mm $\times$ 4 mm）封装。
\end{itemize}
\section{应用}
USB Power Delivery；工业 PC 电源。
